BUILD A PRODUCTION-READY GLOBAL DESIGN MAKER + CYBER CAFE DESIGN OS

You are a senior product architect, UX designer, frontend/backend engineer, database architect, SEO engineer and security engineer.

Build a production-ready web application that makes professional graphic design extremely simple for people who do not know Canva, Photoshop or CorelDRAW.

1. PRODUCT VISION

The core positioning is:

“Canva for people who don’t know Canva.”

Primary message:

“No design skill. No prompt skill. Just tell us what you want.”

Hindi/Hinglish positioning:

“Bas batao kya banana hai — professional design ready.”

IMPORTANT:

This MVP must NOT use any AI API.

Do NOT integrate:

- Gemini API
- OpenAI API
- image-generation APIs
- AI text-generation APIs
- AI question/design generation APIs

However, the architecture MUST be AI-ready so that AI can be added later without rebuilding the editor.

The future AI should act as the brain, while the structured editor acts as the hands.

For example, future commands could be:

- “Naam bada kar do”
- “Photo left kar do”
- “Isko premium bana do”
- “Hindi mein kar do”
- “Background change karo”
- “Same design ka wedding version bana do”

These future commands should ultimately translate into structured design operations/JSON rather than requiring image regeneration for every simple edit.

“Sign in with Google to download and permanently save your design.”

After successful Google login:

9. STRUCTURED DESIGN ENGINE

VERY IMPORTANT:

Do NOT store a design only as a flattened image.

The source of truth must be structured design JSON.

Example concept:

{
  "canvas": {
    "width": 1080,
    "height": 1080,
    "background": "#ffffff"
  },
  "elements": [
    {
      "id": "title-1",
      "type": "text",
      "text": "Happy Birthday",
      "x": 100,
      "y": 100,
      "width": 800,
      "height": 100,
      "fontFamily": "Inter",
      "fontSize": 64,
      "fontWeight": 700,
      "color": "#000000",
      "alignment": "center"
    }
  ]
}

The JSON is the editable source of truth.

PNG/JPG/PDF exports are outputs generated from the structured design.
