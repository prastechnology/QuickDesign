# Dzinewallah

Dzinewallah is a guest-first design maker for posters, invitations, business promotions, and social posts.

## Run locally

- Install dependencies with `npm install`.
- Start the Replit preview with `npm run dev`.
- Build the production bundle with `npm run build`.

The browser editor is available at `/create?template=<template-id>`. It supports editable text, background colors, local photo uploads, undo/redo, local autosave, and PNG/JPG download without requiring an account.
